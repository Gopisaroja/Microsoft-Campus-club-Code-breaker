Your mission is to crack today's hidden numeric code.

  • YELLOW means correct digit but wrong position.

  • You have several attempts.
  • Find the exact code before your attempts run out.

Score = (code length × 100) + (remaining attempts × 50) + max(0, 300 − seconds).
